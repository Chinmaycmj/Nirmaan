The Problem: "The Passive Copier Trap"

Current commercial AI tools (GitHub Copilot, Cursor, ChatGPT) optimize for speed of output rather than depth of cognition. Students suffer from the Illusion of Competence:

✕
Cognitive Atrophy: Students accept 50+ lines of synthesized code without understanding memory lifetimes, state mutations, or edge cases.
✕
Zero Verifiable Provenance: Academic evaluators cannot discern whether code was authored, understood, or blindly pasted.

Pedagogical Framework: Chi's ICAP & ZPD

Nirmaan operationalizes Chi's ICAP Taxonomy (Interactive > Constructive > Active > Passive) inside modern IDE workflows:

Interactive (Highest Mastery) NIRMAAN TARGET

Socratic dialectic, explain-back audits, token syntax deconstruction.

Constructive (High Mastery)

Writing 10-20% core algorithmic gaps inside full architectural scaffolds.

Passive (Low Retention)

Reading 100% LLM auto-generated files (Standard Copilot mode).
